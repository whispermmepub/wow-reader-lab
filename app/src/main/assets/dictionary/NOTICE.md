# WoW Reader offline dictionary data

The bundled `wow_dictionary.db` is a transformed subset of English Wiktionary data extracted through Kaikki.org/Wiktextract. It contains Burmese dictionary entries with English glosses and English entries with Burmese translations.

Dictionary data is distributed under the Creative Commons Attribution-ShareAlike 4.0 International license (CC BY-SA 4.0), consistent with Wiktionary licensing. WoW Reader transforms source data into a compact SQLite lookup database; no images, audio, or example quotations are bundled.

Sources:
- https://en.wiktionary.org/
- https://kaikki.org/dictionary/
- https://github.com/tatuylonen/wiktextract
