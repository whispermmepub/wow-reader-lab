# Historical integration plan

The plan below belongs to the original lab phase. It is not the current roadmap,
feature status or authorization to port to a separate production repository.
This repository's `main` is now the official Android source; see
[current feature status](FEATURE_STATUS.md) and the [README](../README.md).

## Original plan

1. Reading statistics foundation
2. Smart Library status filters and shelves
3. Library-wide notes/highlights hub
4. Per-book typography overrides
5. Smarter backup merge/conflict handling
6. Quote cards

Each phase is developed and verified in the lab before it is considered for the production WoW Reader repository.
