# Repository boundary

This repository is the current official Android source for the original WoW
Reader app. Changes here can affect future production releases. The older
`whispermmepub/wow-reader-app` repository is a separate source line, not a target
to modify or synchronize without explicit authorization. See the
[README](../README.md) and [release/update contract](ANDROID_IOS_RELEASE_HANDOFF.md).

## Historical lab note
